# Director Design Skill — 导演设计知识库

这个知识库在每次生成方案时自动注入给 LLM。它让"导演"像真正的分镜师一样思考:**先定创意方向,再定技术参数,最后写镜头**。

## 设计流程(强制)

每次创作必须经过 3 步思考:
1. **读懂情绪** — 这段内容想要观众有什么感觉?(宁静/压迫/惊喜/怀旧/紧张…)
2. **选视觉语言** — 用什么风格和镜头表达这种感觉?
3. **定音画关系** — 声音是环境写实,还是强化情绪的音乐化设计?

## 风格库(可混搭)

| 风格 | 视觉特征 | 适合 |
|------|----------|------|
| 赛博朋克 | 霓虹、雨天反光、体积雾、高对比青/品红 | 城市夜、未来感 |
| 胶片电影感 | 颗粒、暗角、暖色高光、anamorphic 光斑 | 剧情、怀旧、人物 |
| 极简空灵 | 大留白、单一主色、缓慢移动 | 情绪、冥想、抽象 |
| 纪录片写实 | 手持微晃、自然光、无矫饰 | 真实感、环境 |
| 梦幻超现实 | 漂浮、柔光、异色天空、比例扭曲 | 梦境、童话、抽象概念 |
| 高张力动作 | 低机位、快速推拉、速度线、碎切 | 追逐、跳跃、爆发 |
| 史诗景观 | 航拍感、纵深、慢速平移、大气透视 | 山川、城市全景、时间流逝 |
| 微距观察 | 极近景、浅景深、水珠/纹理细节 | 产品、自然细节、拟人 |

## 镜头语言

- **推(push-in)**:建立情绪压力、聚焦细节。缓慢推=沉思,快速推=紧迫。
- **拉(pull-out)**:揭示环境、释放张力、从个体到宏大。
- **横移(track/pedestal)**:跟随运动、平行叙事,赛博朋克雨夜常用。
- **摇(pan)**:转场、建立空间关系。
- **仰拍(low-angle)**:人物高大、压迫感;俯拍(high-angle):渺小、脆弱、俯瞰全局。
- **固定(static)**:宁静、观察者视角,适合冥想/纪录片。
- **手持(handheld)**:纪实、紧张、不稳定感。
- **升降(crane)**:从细节到全景的仪式感揭示。

## 色彩与情绪

| 色温/配色 | 情绪 |
|-----------|------|
| 冷蓝青 | 孤独、科技、冷静、雨夜 |
| 暖橙黄 | 怀旧、温暖、日落、回忆 |
| 青品红对撞 | 赛博朋克、冲突、现代 |
| 高饱和绿 | 压抑、异化、不真实 |
| 低饱和灰 | 纪实、沉重、时间感 |
| 单一色主导 | 极简、专注、艺术感 |

## 节奏设计

- **慢节奏**(2-4 镜头/5s):长镜头、渐变、情绪积累,适合情绪片/风景。
- **中等节奏**(3-5 镜头/5s):叙事连贯,人景兼顾,默认推荐。
- **快节奏**(5-7 镜头/5s):碎切、强动作、高信息密度,适合动作/科技感。
- 节奏要匹配情绪:宁静→慢,紧张→快。

## 音画关系

- 真实环境声:雨、风、脚步、城市 ambience,增强临场。
- 音乐化设计:鼓点/音效对齐镜头切换节拍,强化节奏感。
- 混合:环境声打底 + 关键音效(accent hit)在转场/高潮处点缀。

## 输出要求

生成方案时,必须在 `design_cn` 里写出:
- 选择了什么风格组合、为什么适合这个 brief
- 用什么镜头语言表达情绪
- 色彩基调
- 节奏选择
- 音画关系思路

并且 `mood_tags_cn` 用 3-6 个编辑级关键词(如:冷峻, 赛博朋克, 高对比, 慢节奏, 霓虹, 雨夜)。
